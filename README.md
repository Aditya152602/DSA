## 🔥 Topic Deep Dives

<details>
<summary><h3>📊 Arrays — The Foundation of DSA</h3></summary>

Arrays are the most fundamental data structure. Everything starts here.

**🔑 Must-Know Patterns:**
- **Two Pointer** — pair sum, container with most water, trapping rain water
- **Sliding Window** — max subarray of size k, longest substring without repeat
- **Prefix Sum** — range sum queries, subarray with given sum
- **Kadane's Algorithm** — maximum subarray sum (O(n))
- **Dutch National Flag** — sort 0s, 1s, 2s in one pass

**🎯 Classic Problems to Master:**
1. Two Sum | Three Sum | Four Sum
2. Best Time to Buy & Sell Stock (I–VI)
3. Trapping Rain Water ⭐
4. Product of Array Except Self ⭐
5. Maximum Product Subarray
6. Find the Duplicate Number
7. Spiral Matrix
8. Set Matrix Zeroes
9. Merge Intervals
10. Next Permutation

**💡 Key Insight:** When brute force is O(n³) or O(n²), think Sorting + Two Pointer or HashMap for O(n log n) or O(n).

</details>

<details>
<summary><h3>🔗 Linked Lists — The Pointer Game</h3></summary>

Linked lists test your understanding of pointers and in-place operations.

**🔑 Must-Know Patterns:**
- **Fast & Slow Pointer** — cycle detection, middle of list, kth from end
- **Reverse** — iterative and recursive reversal, reverse in groups
- **Merge** — merge two sorted lists, sort linked list

**🎯 Classic Problems to Master:**
1. Reverse a Linked List (Iterative + Recursive)
2. Detect & Remove Cycle (Floyd's Algorithm) ⭐⭐
3. Find Middle of Linked List
4. Merge Two Sorted Lists
5. Add Two Numbers
6. Copy List with Random Pointer ⭐⭐
7. LRU Cache (LinkedList + HashMap) ⭐⭐⭐
8. Flatten a Multilevel Linked List

**💡 Key Insight:** When stuck, draw the pointer arrows on paper first. 90% of LL problems become trivial once visualised.

</details>

<details>
<summary><h3>🌲 Trees — The Recursive Paradise</h3></summary>

Trees unlock the power of recursion. Master trees → master recursion.

**🔑 Must-Know Patterns:**
- **DFS (Pre/In/Post order)** — traversal, path problems, subtree queries
- **BFS (Level order)** — level-by-level problems, shortest path in unweighted trees
- **Height/Depth** — diameter, balanced check, LCA
- **BST Properties** — search, insert, delete, kth smallest/largest

**🎯 Classic Problems to Master:**
1. Maximum Depth of Binary Tree
2. Diameter of Binary Tree ⭐
3. Lowest Common Ancestor ⭐⭐
4. Binary Tree Maximum Path Sum ⭐⭐⭐
5. Serialize & Deserialize Binary Tree ⭐⭐⭐
6. Construct Tree from Preorder + Inorder
7. Validate BST
8. Kth Smallest Element in BST
9. Word Search II (Trie) ⭐⭐⭐

**💡 Key Insight:** Almost every tree problem is a DFS where you return something useful from each subtree. Define the return value and the problem solves itself.

</details>

<details>
<summary><h3>🕸️ Graphs — The Boss Level</h3></summary>

Graphs are where beginners become competitive programmers.

**🔑 Must-Know Algorithms:**
- **BFS** — shortest path (unweighted), level traversal
- **DFS** — connected components, cycle detection, topological sort
- **Dijkstra** — shortest path (weighted, non-negative edges)
- **Bellman-Ford** — shortest path (negative edges, negative cycle detection)
- **Floyd-Warshall** — all-pairs shortest path
- **Kruskal / Prim** — Minimum Spanning Tree
- **Union-Find (DSU)** — dynamic connectivity, cycle detection in undirected graph
- **Topological Sort (Kahn's BFS)** — DAG ordering, course prerequisites

**🎯 Classic Problems to Master:**
1. Number of Islands
2. Course Schedule (Cycle Detection in Directed Graph) ⭐⭐
3. Number of Provinces (Union-Find) ⭐
4. Word Ladder (BFS Shortest Path) ⭐⭐
5. Alien Dictionary (Topological Sort) ⭐⭐⭐
6. Network Delay Time (Dijkstra) ⭐⭐
7. Critical Connections (Bridges — Tarjan's) ⭐⭐⭐
8. Cheapest Flights Within K Stops ⭐⭐⭐

</details>

<details>
<summary><h3>💎 Dynamic Programming — The Art of Optimization</h3></summary>

DP is not a technique. It's a **philosophy** — *"Don't recompute what you've already computed."*

**🔑 DP Frameworks:**
- **1D DP** — Fibonacci variants, climbing stairs, house robber
- **2D DP** — Grid paths, edit distance, LCS
- **Knapsack** — 0/1, Unbounded, Fractional
- **Interval DP** — Matrix chain multiplication, Burst balloons
- **Bitmask DP** — TSP, covering all states
- **Tree DP** — DP on trees, rerooting technique
- **Digit DP** — Count numbers with properties in a range
- **DP + Binary Search** — LIS in O(n log n)

**🎯 Classic Problems to Master:**
1. Climbing Stairs / Fibonacci
2. 0/1 Knapsack + all variants ⭐⭐⭐
3. Longest Common Subsequence ⭐⭐
4. Longest Increasing Subsequence ⭐⭐
5. Edit Distance ⭐⭐⭐
6. Coin Change (Count ways + Min coins) ⭐⭐
7. Partition Equal Subset Sum ⭐⭐
8. Burst Balloons ⭐⭐⭐⭐
9. Regular Expression Matching ⭐⭐⭐⭐

**💡 The DP Formula:**
```
1. Define state → dp[i] means what?
2. Find transition → dp[i] = f(dp[i-1], dp[i-2], ...)
3. Identify base cases
4. Determine order of computation
5. Optimise space if needed (rolling array, etc.)
```

</details>

## 🎯 Problem Solving Patterns & Templates

<details>
<summary><h3>🔍 Pattern 1: Sliding Window</h3></summary>

```cpp
// Variable Size Sliding Window Template
int maxLength = 0;
int left = 0;
unordered_map<char, int> freq;

for (int right = 0; right < s.size(); right++) {
    freq[s[right]]++;
    
    // Shrink window if condition violated
    while (/* window is invalid */) {
        freq[s[left]]--;
        if (freq[s[left]] == 0) freq.erase(s[left]);
        left++;
    }
    
    // Update answer
    maxLength = max(maxLength, right - left + 1);
}
return maxLength;
```

**Variants:** Longest substring without repeat, Minimum window substring, Subarray with given sum.

</details>

<details>
<summary><h3>🔍 Pattern 2: Fast & Slow Pointer</h3></summary>

```cpp
// Floyd's Cycle Detection
ListNode* slow = head;
ListNode* fast = head;

while (fast && fast->next) {
    slow = slow->next;
    fast = fast->next->next;
    if (slow == fast) {
        // Cycle detected!
        // Find cycle start:
        slow = head;
        while (slow != fast) {
            slow = slow->next;
            fast = fast->next;
        }
        return slow; // Start of cycle
    }
}
return nullptr; // No cycle
```

</details>

<details>
<summary><h3>🔍 Pattern 3: Binary Search Template</h3></summary>

```cpp
// Generalised Binary Search (find first true)
int lo = 0, hi = n - 1;
int ans = -1;

while (lo <= hi) {
    int mid = lo + (hi - lo) / 2;  // Avoid overflow!
    
    if (condition(mid)) {
        ans = mid;      // Candidate found
        hi = mid - 1;   // Look for earlier/better
    } else {
        lo = mid + 1;   // Move right
    }
}
return ans;
```

**When to use:** Any monotonic condition — "find minimum X such that f(X) is true."

</details>

<details>
<summary><h3>🔍 Pattern 4: Monotonic Stack</h3></summary>

```cpp
// Next Greater Element (Monotonic Decreasing Stack)
stack<int> st;
vector<int> result(nums.size(), -1);

for (int i = 0; i < nums.size(); i++) {
    // Pop elements smaller than current
    while (!st.empty() && nums[st.top()] < nums[i]) {
        result[st.top()] = nums[i];
        st.pop();
    }
    st.push(i);
}
return result;
```

**Variants:** Next Greater Element I/II, Trapping Rain Water, Largest Rectangle in Histogram.

</details>

<details>
<summary><h3>🔍 Pattern 5: Union-Find (DSU)</h3></summary>

```cpp
class DSU {
    vector<int> parent, rank;
public:
    DSU(int n) : parent(n), rank(n, 0) {
        iota(parent.begin(), parent.end(), 0);
    }
    
    int find(int x) {
        if (parent[x] != x)
            parent[x] = find(parent[x]); // Path compression
        return parent[x];
    }
    
    bool unite(int x, int y) {
        int px = find(x), py = find(y);
        if (px == py) return false; // Already same set
        // Union by rank
        if (rank[px] < rank[py]) swap(px, py);
        parent[py] = px;
        if (rank[px] == rank[py]) rank[px]++;
        return true;
    }
};
```

</details>
